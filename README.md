# Biomedical ML for Tuberculosis Biomarker Discovery

## Overview

This project develops machine learning models for tuberculosis biomarker discovery using human transcriptomic datasets.

The objective is to identify biologically meaningful gene signatures capable of distinguishing active tuberculosis from healthy controls while maintaining model interpretability through explainable AI techniques.

## Project Highlights

- Transcriptomic data preprocessing
- Multi-model feature selection
- Logistic Regression
- Random Forest
- Support Vector Machine
- XGBoost
- SHAP explainability
- Biomarker panel development
- External validation
